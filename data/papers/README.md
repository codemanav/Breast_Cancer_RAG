# Research papers

Research-paper PDFs used as literature for retrieval. `pipeline.py index`
splits each PDF into overlapping chunks, keeps the paper name and page number
for citations, and adds them to the vector store alongside the evidence cards.
Add more PDFs to this folder and rerun `python pipeline.py index`.
